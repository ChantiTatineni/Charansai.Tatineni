# Charansai Tatineni · Monza portfolio

A drivable 3D portfolio set on the Autodromo Nazionale di Monza layout.
This repository holds the built site that Netlify serves.

- `index.html`: the 3D driving portfolio
- `resume.html`: a plain, fast résumé page for recruiters

The engine is Bruno Simon's folio-2025 (MIT license), heavily modified:
new map, F1 car, content and areas. Track outline from bacinger/f1-circuits.
